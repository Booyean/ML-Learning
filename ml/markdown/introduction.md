# 写在最前面的
## 一些思考
笔者（因为是敲键盘和点鼠标，不应该叫笔者，因自称**键人和鼠辈**）作为计算机文盲，对计算机了解很少。在学长的“~~色诱下~~”决心学好机器学习。奈何基础太过薄弱，纵使在网络资源和纸质资源如此发达的今天，自学ML对我来说仍是一场艰难且路径模糊的马拉松。

所以我突发奇想，决定更系统性更书面化的记录我的学习过程和问题，我的碰壁流程和思维缺陷，既是请求先进们的指导，也是为来年的后进们开辟一条真真正正的**零基础ML学习日记**，用于借鉴和嘲笑。所以内部难免会有繁琐的文字用于谱写**心得**，有长长的篇幅讲述我学习ML之外但又不得不学的默认的**相关知识**（硬件知识、数学知识等），有显示的笨拙但真诚且稚嫩的**知识笔记**。

诚然是一场盛大的朝圣之路，在谱写这些手札之时，我真真正正地体会到自由学习的无限乐趣和非凡的成就感。这种体验，是我前十八年的生命里前所未有的。

谨以此文，聊表拳拳之心，开启我的ML马拉松
