# 前置知识
## 1.关于 *markdown* 的语法知识
### （1）基础语法  
“#”的多少关乎标题的大小（最多六级标题，本人蠢蠢试过...）；
两端“*”用于表示斜体 e.g *斜体*；
两端“**”用于表示加粗字体 e.g **加粗**；
两端“~~”用于表示中划线 e.g ~~中划线~~； 
注意以上的语法可以套用 e.g   ~~***混用***~~
连续的三个单星号表示分割线 e.g ;
***
### （2）列表处理
* “* ”为无序列表；
* 此为无序列表；

        * 此为三级列表；

   2. 此为二级列表；
        1. 此为三级列表；

        此为提行；
